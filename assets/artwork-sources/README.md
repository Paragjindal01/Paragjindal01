# GitHub artwork source plates

These optimized WebP plates were created with Higgsfield GPT Image 2.6 for this independent engineering profile. The artwork is conceptual and depicts fictional hardware. No real deployment, employee, or facility is represented.

- [Engineering plate](engineering-plate.webp) is the text-free source of the [GitHub banner](../engineering-profile.webp).
- [Product concept plate](product-concept-plate.webp) is the source of the [six flagship covers](https://github.com/Paragjindal01/paragjindal-portfolio/tree/main/docs/artwork).

The portfolio’s application screenshots were captured separately from running software. These files remain in the repositories for use independently of temporary generation links.
